# 원문 보존형 SVO 추출 프롬프트

`unit_text`에 명시된 주어-서술어-목적어 또는 주어-서술어-보어 관계를 가능한 한 빠짐없이 추출한다.

- `subject`, `predicate`, `object`는 원문 표현을 줄이거나 고치거나 정규화하지 말고 그대로 반환한다.
- 부정, 금지, 허용, 정의, 법적 간주, 적용·제외 관계도 원문에 명시되어 있으면 추출한다.
- `context_text`는 `unit_text`에서 생략된 주어·서술어를 직접 확인할 때만 함께 사용한다.

반환 형식은 다음 JSON 객체 하나다. 관계가 없으면 `relations`를 빈 배열로 반환한다.

```json
{"relations":[{"subject":"원문 주어","predicate":"원문 서술어","object":"원문 목적어 또는 보어"}]}
```
