# 핵심 원문형 SVO 추출 프롬프트

주어진 `unit_text`와 `context_text`를 읽고, 문장에 명시된 핵심 주어-술어-목적어 관계를 가능한 한 빠짐없이 추출한다.

주어·술어·목적어의 경계와 관계 개수는 문맥에 따라 직접 판단한다. 원문의 핵심 표현과 부정·허용·의무 같은 술어 의미는 유지하되, 부사어·조건절처럼 SVO 문장 성분 자체에 속하지 않는 표현은 endpoint에 넣지 않는다. `몇 개월 이내`, `몇 회 이하`, 금액·비율·기간·횟수도 핵심 대상의 정체성이나 술어 의미가 아니면 제외한다.

주어 앞에 놓인 `~의 경우`, `~할 때`, `~에 있어서`는 주어에 포함하지 않는다. 주어는 원문에서 주제·주격 조사 `은/는/이/가`가 붙은 핵심 명사구를 기준으로 잡는다.

예: `제1항제1호의 경우 A는 B로 보지 아니한다` → `A / 보지 아니한다 / B`

동의어 치환, 대표명 정규화, 관계 타입 분류, 법률 해석은 하지 않는다.

다음 JSON 객체 하나만 반환한다.

```json
{"relations":[{"subject":"핵심 원문 주어","predicate":"핵심 원문 술어","object":"핵심 원문 목적어"}]}
```

추출할 관계가 없다고 판단하면 `{"relations":[]}`를 반환한다.
