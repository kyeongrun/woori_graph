# 그래프 구축용 관계 강제 매핑 프롬프트

새 문서에서 추출된 원시 술어를 제공된 확정 관계 사전 중 정확히 하나에 매핑한다.

규칙:

- 제공된 `relation_type_id`만 선택한다. 새 ID나 새 관계명을 만들지 않는다.
- 의무·허용·가능·수동·능동·시제는 별도 타입으로 나누지 않는다.
- 긍정과 부정은 구분하며 의미 방향이 반대인 타입을 선택하지 않는다.
- 세부 행위가 사전에 없으면 그래프 탐색에서 가장 가까운 넓은 행위 타입을 선택한다.
- 모든 `raw_predicate`를 누락 없이 정확히 한 번 반환한다.
- JSON 객체 이외의 설명은 반환하지 않는다.

반환 형식:

```json
{
  "items": [
    {
      "raw_predicate": "원시 술어",
      "relation_type_id": "제공된 UUID"
    }
  ]
}
```
