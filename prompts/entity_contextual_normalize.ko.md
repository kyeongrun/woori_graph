# 문맥 기반 엔티티 대표명 재정규화 프롬프트

법령·내규 SVO의 모든 raw 엔티티를 검색용 canonical name으로 정규화한다. 현재 표면명, aliases, 실제 원문 문맥을 함께 보고 각 입력의 정체성을 직접 판단한다. 일부 후보만 고르는 단계가 아니며 입력된 모든 엔티티에 대해 LLM이 canonical_name을 선정한다.

판단 순서:

1. 원문 문맥에서 엔티티가 실제로 가리키는 대상·문서·개념을 확인한다.
2. 동일 대상을 가리키는 띄어쓰기, 조사, 소유격, 약칭, 문서 접미어, 명사화 차이를 제거한다.
3. 검색 결과를 같은 묶음으로 보는 편이 유용한 가까운 동의 표현은 약간의 의미 변형·생략을 허용해 하나로 통합한다.
4. 대표명은 가장 자연스럽고 짧은 도메인 명사구를 선택한다.
5. 서로 관련되어 있을 뿐 동일 검색 개념이 아닌 기관·직위·법령·행위·문서는 합치지 않는다. 확신이 없으면 현재 이름을 유지한다.

일반 정규화 규칙:

- 동일 기관·사람 직위·법령·문서·도메인 개념의 약칭, 띄어쓰기, 따옴표, 조사·어미 차이는 같은 canonical_name으로 합친다.
- 불필요한 `의`, 중복 소속어, `상근` 같은 비핵심 상태, 뒤에 붙은 `업무`, `조치`, `사항` 같은 포괄어는 제거할 수 있다. 단, 제거하면 다른 대상을 가리키게 되는 소속·직위·문서 종류는 유지한다.
- `기재/표시`, `보고서/확인서`, `금액/대금`처럼 이 문서 집합에서 같은 검색 대상을 나타내는 가까운 용어는 대표 용어 하나로 통합할 수 있다. 단순히 연관된 모든 단어를 동의어로 보지는 않는다.
- 금액·기간·인원·연령·촌수·급수·비율·횟수 등 핵심 일반명사를 수식하는 부수 조건은 제거하고 핵심 명사를 남긴다.
- `퇴직 후 2년이 지나지 않은 사람`처럼 기간을 포함한 전체 표현이 하나의 사람 범주·자격 상태 자체이면 `사람`으로 축약하지 않고 현재 표현을 보존한다. 기간을 별도 엔티티로 만들지는 않는다.
- `X법에 따른 A`, `X법 제N조에 따라 지정된 A`, `제N조에 따른 A`, `대통령령으로 정하는 A`에서 법령·조문이 A의 근거 수식어이면 A만 남긴다.
- 법령이나 조문 자체가 실제 endpoint이면 조·항·호를 제거하고 정식 법령명으로 합친다. `법 제N조`처럼 현재 문서를 가리키면 문맥의 document_title을 사용한다.
- `제3자`, `1차 시험`, 고유 상품명처럼 숫자가 정체성의 일부이면 숫자를 제거하지 않는다.
- `금융지주회사의 자회사`, `회사의 감사`처럼 소유·소속 문맥이 다른 대상을 구분하는 데 필요하면 유지한다.
- `위원회`, `회사`, `담당부서`, `담당자`, `임원`, `대표자` 같은 일반 표현은 문맥의 정식 명칭으로 치환하지 않는다.
- `이 법`, `이 영`, `이 규칙`, `이 규정`은 이 단계 전에 현재 문서명으로 해소되어야 하며 global alias로 만들지 않는다.
- 조건을 제거한 결과가 `자`, `사람`, `사항`, `내용`, `대상`, `업무`, `행위`, `것`, `경우`, `금액`, `기간`, `비율` 같은 일반명사만 남는다면 임의로 축약하지 않는다. 문맥에서 구체적인 핵심 엔티티를 찾고 찾지 못하면 현재 이름을 유지한다.
- 입력의 모든 source_entity_id를 정확히 한 번 반환하고 새 ID를 만들지 않는다.
- 규칙 기반 후처리가 이름을 대신 선정하지 않으므로, 최종적으로 사용할 canonical_name을 이 응답에서 완결되게 결정한다.
- JSON 객체 이외의 설명은 반환하지 않는다.

기준 예시:

- `감사위원회 위원` → `감사위원`
- `감사의 목적, 필요성` → `감사의 목적`
- `감사인력의 지원` → `감사인력 지원`
- `거래소의 상근 임직원` → `거래소의 임직원`
- `거짓의 기재` → `거짓의 표시`
- `검증보고서` → `검증확인서`
- `결제금액` → `결제대금`
- `경고조치`, `경고 등 적절한 조치` → `경고`
- `심의회의 업무` → `심의회의`

반환 형식:

```json
{"items":[{"source_entity_id":"입력 ID","canonical_name":"정규화 이름"}]}
```
