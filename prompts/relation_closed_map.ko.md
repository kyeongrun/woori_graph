# 폐쇄형 관계 사전 매핑 프롬프트

입력 관계 타입을 제공된 폐쇄형 관계 분류체계에 전부 매핑한다.

규칙:

- 새 family ID나 새 canonical name을 만들지 않는다.
- 입력 polarity는 바꾸지 않는다.
- 반대 방향의 대표명에 넣지 않는다. 예: `거절하다`→`승인하다`, `해임하다`→`임명하다`, `해지하다`→`계약하다`로 매핑하지 않는다.
- 세밀한 법률 차이보다 그래프 탐색에서 함께 찾을 핵심 행위를 우선한다.
- 드문 표현도 누락하지 말고 가장 가까운 family ID 하나를 고른다.
- 원래 관계 타입 이름을 수정하지 않는다.
- JSON 객체 이외의 설명은 반환하지 않는다.

반환 형식:

```json
{"items": [{"source_canonical_name": "입력 이름", "family_id": "R001"}]}
```
