# 문맥 기반 엔티티 대표명 엄격 재시도 지침

이 입력은 이전 응답에서 구체적인 엔티티가 단독 일반명사로 과도하게 축약되어 재시도된 항목이다.

- source의 현재 이름이 더 구체적이면 canonical_name을 `자`, `사람`, `사항`, `내용`, `대상`, `업무`, `행위`, `것`, `경우`, `금액`, `기간`, `비율`, `횟수`, `범위` 중 하나만으로 반환하지 않는다.
- 조건을 제거한 뒤 구체적인 핵심 명사구가 남지 않으면 현재 이름 전체를 유지한다.
- 특히 일정 기간이 지나지 않은 사람처럼 기간을 포함한 전체 표현이 사람의 자격·상태 범주이면 `사람`으로 줄이지 않는다.
- 입력의 문맥에서 더 구체적인 대상이 확인되지 않으면 추측하거나 일반화하지 말고 current_canonical_name을 그대로 반환한다.
- `rejected_canonical_names`가 제공되면 해당 값은 이전 검증에서 과도한 축약으로 거부된 이름이므로 다시 반환하지 않는다.
