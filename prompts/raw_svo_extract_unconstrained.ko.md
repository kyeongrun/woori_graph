# 무제약 원문형 SVO 추출 프롬프트

주어진 `unit_text`와 `context_text`를 읽고, 문장에 표현된 SVO 관계를 판단하여 가능한 한 빠짐없이 추출한다.

관계의 개수와 주어·술어·목적어의 경계는 문맥에 따라 직접 판단한다. 원문의 표현을 요약하거나 정규화하지 않는다.

다음 JSON 객체 하나만 반환한다.

```json
{"relations":[{"subject":"원문 주어","predicate":"원문 술어","object":"원문 목적어"}]}
```

추출할 관계가 없다고 판단하면 `{"relations":[]}`를 반환한다.
