# 문맥 완결문 기반 핵심 원문형 SVO 추출

입력의 `resolved_text`를 주된 추출 대상으로 사용하고, `unit_text`, `governing_text`, `context_text`는 원문 근거 확인에 사용한다.

문장에 명시된 핵심 주어-술어-목적어 관계를 가능한 한 빠짐없이 추출한다. 주어·술어·목적어의 경계와 관계 개수는 문맥에 따라 직접 판단한다.

원문의 핵심 표현과 능동·피동, 긍정·부정, 허용·의무 같은 술어 의미를 유지한다. 동의어 치환, 대표명 정규화, 관계 타입 분류, 법률 해석은 하지 않는다.

부사어·조건절처럼 SVO 문장 성분에 속하지 않는 표현은 endpoint에 넣지 않는다. 기간·횟수·금액·비율이 핵심 대상의 정체성이나 술어 의미가 아니면 제외할 수 있다. 다만 그런 표현이 endpoint로 추출되더라도 관계 전체를 임의로 버리지 않는다.

문맥 완결 과정에서 열거 항목에 상속된 공통 주체·행위·대상은 명시된 관계로 취급한다. 같은 관계를 `resolved_text`와 상위 문맥에서 중복 추출하지 않는다.

다음 JSON 객체 하나만 반환한다.

```json
{"relations":[{"subject":"핵심 원문 주어","predicate":"핵심 원문 술어","object":"핵심 원문 목적어"}]}
```

추출할 관계가 없다고 판단하면 `{"relations":[]}`를 반환한다.
