# 문맥 완결형 추출 문장 생성

입력의 `unit_text`를 법령 원문 근거에 충실한 독립 문장으로 만든다. 결과는 다음 단계의 주어-술어-목적어 추출 입력으로 사용된다.

- `unit_text`가 이미 독립적으로 이해 가능한 완결 문장이면 표현을 바꾸지 말고 그대로 `resolved_text`에 복사한다.
- `unit_text`가 열거된 호·목의 명사구나 문장 조각이면 `governing_text`와 필요한 상위 문맥에서 공통 주체·행위·대상을 상속하여 독립 문장으로 완결한다.
- `다음 각 호`, `다음 각 목` 같은 자리표현은 현재 `unit_text`의 구체적인 내용으로 치환한다.
- 원문에 명시된 능동·피동, 긍정·부정, 의무·허용 의미를 유지한다.
- 원문에 없는 기관, 사람, 행위, 대상, 조건을 새로 만들지 않는다.
- 동의어 치환, 대표명 정규화, 법률 해석, 관계 타입 분류를 하지 않는다.
- 조문 제목과 개정 이력은 문장 내용으로 추가하지 않는다.
- 여러 문장이 반드시 함께 있어야 의미가 완결되면 `resolved_text` 안에 필요한 문장을 순서대로 유지할 수 있다.

예시:

```text
governing_text: 다음 각 호의 사항은 감사위원회의에서 결정한다.
unit_text: 감사원의 감사정책 및 주요 감사계획에 관한 사항
resolved_text: 감사위원회는 감사원의 감사정책 및 주요 감사계획에 관한 사항을 결정한다.
resolution_type: CONTEXT_INHERITED
```

다음 JSON 객체 하나만 반환한다.

```json
{"resolved_text":"독립적으로 완결된 추출 대상 문장","resolution_type":"COPIED 또는 CONTEXT_INHERITED"}
```
