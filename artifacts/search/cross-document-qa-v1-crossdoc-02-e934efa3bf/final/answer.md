질문: ‘투자회사’와 ‘상호회사 사원총회’는 ‘상법’를 거쳐 어떻게 연결되며, 각 연결의 근거 법령은 무엇인가?

그래프와 법령 근거에서 확인된 주요 연결은 다음과 같습니다.

1. 상법 - 적용하지않다 → 투자회사 / 상호회사 - 적용하다 → 상법 (근거 문서: 보험업법, 자본시장과 금융투자업에 관한 법률)
   - 근거: 자본시장과 금융투자업에 관한 법률 제206조 제2항; 원표현: 「상법」 제383조 - 적용하지 아니한다 → 투자회사
   - 근거: 보험업법 제44조; 원표현: 상호회사 - 준용한다 → 「상법」

2. 상법 - 적용하지않다 → 투자회사 / 상호회사 - 적용하다 → 상법 / 상호회사 - 지급하다 → 사원 (근거 문서: 보험업법, 자본시장과 금융투자업에 관한 법률)
   - 근거: 자본시장과 금융투자업에 관한 법률 제206조 제2항; 원표현: 「상법」 제383조 - 적용하지 아니한다 → 투자회사
   - 근거: 보험업법 제44조; 원표현: 상호회사 - 준용한다 → 「상법」
   - 근거: 보험업법 제63조; 원표현: 상호회사 - 분배한다 → 사원

3. 상법 - 적용하지않다 → 투자회사 / 상호회사 - 적용하다 → 상법 / 상호회사 - 설립하다 → 사원 (근거 문서: 보험업법, 자본시장과 금융투자업에 관한 법률)
   - 근거: 자본시장과 금융투자업에 관한 법률 제206조 제2항; 원표현: 「상법」 제383조 - 적용하지 아니한다 → 투자회사
   - 근거: 보험업법 제44조; 원표현: 상호회사 - 준용한다 → 「상법」
   - 근거: 보험업법 제37조; 원표현: 상호회사 - 설립한다 → 사원

4. 상법 - 적용하지않다 → 투자회사 / 상호회사 사원총회 - 적용하다 → 상법 (근거 문서: 보험업법, 자본시장과 금융투자업에 관한 법률)
   - 근거: 자본시장과 금융투자업에 관한 법률 제206조 제2항; 원표현: 「상법」 제383조 - 적용하지 아니한다 → 투자회사
   - 근거: 보험업법 제59조 제1항; 원표현: 상호회사의 사원총회 - 준용한다 → 「상법」 제367조

5. 상법 - 적용하지않다 → 투자회사 / 투자회사 - 등록하다 → 상호 (근거 문서: 자본시장과 금융투자업에 관한 법률)
   - 근거: 자본시장과 금융투자업에 관한 법률 제206조 제2항; 원표현: 「상법」 제383조 - 적용하지 아니한다 → 투자회사
   - 근거: 자본시장과 금융투자업에 관한 법률 제202조 제2항 1; 원표현: 투자회사 - 등기하여야 한다 → 상호
