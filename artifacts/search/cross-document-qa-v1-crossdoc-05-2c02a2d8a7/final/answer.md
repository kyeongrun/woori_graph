질문: ‘금융위원회’와 ‘법원’는 ‘등록’를 거쳐 어떻게 연결되며, 각 연결의 근거 법령은 무엇인가?

그래프와 법령 근거에서 확인된 주요 연결은 다음과 같습니다.

1. 금융위원회 - 수행하다 → 등록 / 법원 - 임명하다 → 등록 (근거 문서: 보험업법 시행령, 신탁법)
   - 근거: 보험업법 시행령 제102조 제2항 6; 원표현: 금융위원회 - 처리할 수 있다 → 등록
   - 근거: 신탁법 제20조 제1항 1; 원표현: 법원 - 촉탁하여야 한다 → 등록

2. 법원 - 수행하다 → 금융위원회 / 법원 - 임명하다 → 등록 (근거 문서: 신탁법, 자본시장과 금융투자업에 관한 법률)
   - 근거: 자본시장과 금융투자업에 관한 법률 제217조의7 제1항; 원표현: 법원 - 본다 → 금융위원회
   - 근거: 신탁법 제20조 제1항 1; 원표현: 법원 - 촉탁하여야 한다 → 등록

3. 금융위원회 - 취소하다 → 등록 / 법원 - 임명하다 → 등록 (근거 문서: 개인금융채권의 관리 및 개인금융채무자의 보호에 관한 법률, 보험업법, 신탁법, 자본시장과 금융투자업에 관한 법률)
   - 근거: 보험업법 제86조 제1항 1; 원표현: 금융위원회 - 취소하여야 한다 → 등록
   - 근거: 개인금융채권의 관리 및 개인금융채무자의 보호에 관한 법률 제42조 제5항; 원표현: 금융위원회 - 취소할 수 있다 → 등록
   - 근거: 자본시장과 금융투자업에 관한 법률 제20조의2 제1항 1; 원표현: 금융위원회 - 말소할 수 있다 → 등록
   - 근거: 신탁법 제20조 제1항 1; 원표현: 법원 - 촉탁하여야 한다 → 등록

4. 금융위원회 - 수행하다 → 등록 / 금융위원회 - 취소하다 → 인가 (근거 문서: 금융지주회사법, 보험업법 시행령, 은행법, 자본시장과 금융투자업에 관한 법률)
   - 근거: 보험업법 시행령 제102조 제2항 6; 원표현: 금융위원회 - 처리할 수 있다 → 등록
   - 근거: 은행법 제60조 제1항 1; 원표현: 금융위원회 - 취소할 수 있다 → 인가
   - 근거: 금융지주회사법 제57조 제2항 1; 원표현: 금융위원회 - 취소할 수 있다 → 인가
   - 근거: 자본시장과 금융투자업에 관한 법률 제323조의20 제1항 1; 원표현: 금융위원회 - 취소할 수 있다 → 인가

5. 금융위원회 - 수행하다 → 등록 / 금융위원회 - 공개하다 → 인가 (근거 문서: 보험업법 시행령, 상호저축은행법, 은행법)
   - 근거: 보험업법 시행령 제102조 제2항 6; 원표현: 금융위원회 - 처리할 수 있다 → 등록
   - 근거: 은행법 제12조; 원표현: 금융위원회 - 공고하고 → 인가
   - 근거: 상호저축은행법 제6조의3; 원표현: 금융위원회 - 공고하고 → 인가
